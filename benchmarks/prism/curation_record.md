- Source: 68,371 model utterances in 8,011 PRISM conversations, with original human ratings, selection flags, moderation metadata and published model configurations. Retain the separate human-text and model-output licenses.
- Transformation: five table stages make the 21 generating models the subjects and preserve anonymous human raters as interactors. Each generation has two measures: its native 1-100 rating and chosen flag; neither is regraded or normalized.
- Context and conventions: items contain prior selected turns plus the current user prompt. Keep 265 turns with duplicate chosen texts and 147 literal EMPTY STRING markers. Unavailable manual PII flags use null in trace JSON instead of the source NaN sentinel; raw bytes stay unchanged. Per-model headers/settings are documented configurations, not verified request logs; survey demographics are not imported.
- Validation: check every utterance against its original conversation, model, rater, output and metadata; test corrupted associations and a fresh upstream rebuild. Preserve the whole previous builder folder. No model execution, new grading or re-identification.
