# Harness Buy SWE-bench Verified curation record

- **Coverage.** The 6,879 non-excluded no-web SWE-bench Verified trials in `data/trials.csv` (seven models, four harnesses, nine arms, 492 tasks, run 2026-09-02 to 09-20) become 6,431 responses for 48 subjects under the authors' canonical rule (448 retries superseded); they reproduce Tables 1, 2, A5 and A6 exactly. The pin is `3f0c132`, the initial release published with arXiv v1; there are no tags, and later commits change only the README, citation and figures. The 897 web-enabled trials are excluded: the authors' leakage audit (`analysis/web_leakage.csv`) found 312 of 439 DeepSeek and Qwen web-enabled trials (71%) calling for the upstream fix, the authors replaced those arms with no-web reruns, and those runs used Harbor's unpatched registry tasks, so a different grader. Also excluded: 91 trials the authors flagged (smoke tests, crashes, a DeepSeek WebSearch leak) and 165 Terminal-Bench 2.1 trials (another task bank).
- **Curation decisions.** Subjects are registry keys; Qwen3.8-27B, GLM-5.3-Flash and HY4-Preview were added with model and company only, as the sources give no release dates. Features: harness, exact per-trial harness version (33 arms → 48 subjects), the released arm as `tool_mode` (`cc-v1.0.100-nw` → `control-nw`, version 1.0.100), and reasoning effort where every job configuration of an arm states it. Seeds are trials (`attempt` in packed k=2 jobs); no retry fills two seeds. The 63 nulls are slots whose every attempt hit one of `main_table.py`'s 14 infrastructure exceptions, including 4 rewarded `cc_api_error` trials. Unversioned ungraded trials take their job's single version. Content is the SWE-bench Verified problem statement at `c104f840` (unchanged since 2025-02-18), Harbor's instruction verbatim; the grader never reads the gold patch, so there is no reference answer. The verifier records Harbor 0.22.0's test script (`4407eb5`), swebench 4.0.3, test patch, FAIL_TO_PASS/PASS_TO_PASS and the authors' test-script patches.
- **Limitations.** Harbor's task package (`sha256:b934b0cc…`) and the patched tasks are not public, so the verifier is reconstructed; the patches were applied mid-study (new-file cleanup from 2026-09-08). 2,585 kept trials from 38 of 100 jobs, including every Opus tool-removal, Claude Code 1.0.100 and B36 run, have no released configuration, only notes in `extract_trials.py`. B36/B38 are unreported and their no-web status is inferred. Agents still attempted fix lookups under the no-web allowlist, which blocked them; the authors' content audit needs unreleased trajectories, so there are no traces. API snapshots and Docker images are unpinned; tokens and cost are not stored. Data CC BY 4.0, code MIT.

Sources and grading are documented in [metadata.yaml](metadata.yaml); reviewed counts and checks are in [characterization.yaml](characterization.yaml) and [shared dataset checks](../../tests/test_benchmark_datasets.py).
