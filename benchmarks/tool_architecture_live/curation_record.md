# Tool Architecture SWE-bench Live curation record

- **Coverage.** All 11,700 main-study attempts in the authors' data archive (SHA-256 `59b0e867…`): Qwen3Coder-30B, Kimi K2.5 and Claude Sonnet 4.5 × BashOnly, Atomic, NLSearch, HypoTrack, ScratchPad and Python × 65 SWE-bench Live tasks × 10 repeats. Grades are `figure4/inputs.json` `resolved`; they equal Table 2's all-attempt outcomes once its failures for unfinished attempts are restored to null. The 548 attempts with no patch were never evaluated and stay null (361 Qwen, 98 Kimi, 89 Sonnet). Excluded: the 30-repeat consistency cohort, which re-ran 14 main attempts with 13 different grades, and the Verified, Pro and Debugging cohorts, which use other task banks. No agent was re-run.
- **Curation decisions.** The tool architecture is the `tool_mode` subject feature; `harness` is `trae_agent` for five architectures and `simple_agent` for Python. Model labels map to registry keys; `Qwen3-Coder-30B-A3B-Instruct` is inferred, as the paper names only Qwen3Coder-30B. Repeats 0–9 are trials 1–10. The bundled task file selects the 65 tasks; definitions come from SWE-bench Live `verified` at `b51a864`, which matches it exactly and whose file is byte-identical from 2025-09-18 onward. The grader is pinned to `microsoft/SWE-bench-Live` `ad79b850`, the branch tip the runners cloned; its `swebench/` package is unchanged since 2025-07-18. Content keeps the verified text verbatim. `conan-io__conan-18153` has two verified rows with different `test_cmds`; the item uses the one matching the bundled file and records the other in its verifier, because the grader keeps both and the verdict's source is ambiguous (0 of 180 attempts resolved). Traces are the complete released trajectories.
- **Limitations.** The repository's single commit postdates the runs, so the agent code that ran is unproven. Docker images use the moving `latest` tag, model endpoints are configuration placeholders, and the NLSearch search subagent defaults to Qwen3Coder-30B without a per-run record. Python changes the interface, the agent loop and max_tokens (8192 vs 4096) together. Trae trajectories record `\r\n` as `\n` in 33 tasks' statements. Run dates are not released; file timestamps in trajectories suggest late January to late February 2026. The license of the released data is unknown.

Sources and grading are documented in [metadata.yaml](metadata.yaml); reviewed counts and checks are in [characterization.yaml](characterization.yaml) and [shared dataset checks](../../tests/test_benchmark_datasets.py).
