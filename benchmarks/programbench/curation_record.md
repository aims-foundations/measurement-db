- Sources: the pinned official submission registry and all 25 linked author repositories; 4,965 full trajectories and 4,964 evaluations. No model, container or grader was executed.
- Transformation: each active published Boolean test becomes a binary item outcome. `testlet_id` groups tests by original program task; `attempt_id` links all outcomes from one execution to its complete trajectory, stored once in `attempts.parquet`. Preserve all 28 recorded configurations, initial messages and original container references. The one execution without a released evaluation remains an attempt without fabricated test outcomes; repeated native test records remain in its trace.
- Aggregation: recover a task score by averaging the active test outcomes from one attempt. The upstream convention gives an explicitly published empty map a task score of zero, while an absent evaluation stays unavailable; neither creates an individual test outcome. To reproduce a macro-average over tasks, average the task scores; pooling individual tests would overweight programs with more tests. Grader and prompt variants keep distinct item identities within the same testlet.
- Version change: replaces the older 15-run scrape and 0/1/2 threshold categories with the complete newer native release. The archived older collection preserves all 2,995 cells, including 16 absent from these forks; one overlapping threshold category changes under the newer grading record.
- Limits and checks: historical container bytes and external submission/log archives are referenced, not captured here. Every published test verdict, input/configuration association and full trace is independently checked; tests exercise corruption and missing evaluations. Result repositories lack redistribution terms, so captured inputs and tables remain local.
