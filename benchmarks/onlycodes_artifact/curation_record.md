# Onlycodes Artifact curation record

- **Coverage.** All 1,674 released artifact-suite attempts in `paper/data/raw/all_results.csv`: Claude Code (claude-sonnet-4-6) and Codex CLI (gpt-5.5, 0.130.0) × baseline, bash_only and code_only × 93 tasks in nine categories × 3 seeds. Sources are pinned to `93740e5`, which the authors' `kdd-se3-ws-2026-submission` release names as the paper's snapshot; the intervention pilot's later pin `7548222` has an identical results CSV and task files but six post-paper harness changes, including the baseline tool-surface fix (#334). Grades match the CSV row for row, and per-arm pass rates equal the authors' `paired_marginals.csv`. 1,638 attempts pass (97.8%), so most items do not separate subjects. The SWE-bench suite is the separate `onlycodes_swe` benchmark because it is graded differently. No agent was re-run.
- **Curation decisions.** The model is the registry-mapped subject label; harness, version and arm are subject features, with the arm as `tool_mode` and the released label `tool_rich` as `baseline`. Claude attempts keep their recorded Claude Code version (2.1.132 or 2.1.139), so 32 tasks have seeds split between two subjects; trials keep the released seed. Content is `prompt.md`; committed `workspace/` files are attachments. The generator is marked `workspace_generator`: the harness withholds it from the agent and runs it with a seed derived from the task ID to write the input data. The verifier stores the `hidden.py` source; the grader runs in a subprocess with a 120 s timeout, and only its `passed` flag is the grade. Only the four graders that read their committed reference output have a reference answer.
- **Limitations.** Agent identity combines model and harness, so cross-agent gaps do not isolate the model. Generated input data is not stored, and the generators were not executed here; harness prompt wrappers are not stored. Baseline runs predate #334; Codex restrictions add a prompt directive. Declared execution budgets were not enforced, and one PASS ran 4,441 s, beyond the 3,600 s default. Per-run logs are not released, so there are no traces.

Sources and grading are documented in [metadata.yaml](metadata.yaml); reviewed counts and checks are in [characterization.yaml](characterization.yaml) and [shared dataset checks](../../tests/test_benchmark_datasets.py).
