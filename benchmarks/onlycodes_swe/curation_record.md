# Onlycodes SWE-bench Mini curation record

- **Coverage.** All 1,800 released SWE-bench Mini attempts in `paper/data/raw/all_results.csv`: Claude Code (claude-sonnet-4-6, 2.1.139) and Codex CLI (gpt-5.5, 0.130.0) × baseline, bash_only and code_only × 100 tasks × 3 seeds. Sources are pinned to `93740e5`, which the authors' `kdd-se3-ws-2026-submission` release names as the paper's snapshot; the intervention pilot's later pin `7548222` has an identical results CSV and task files but six post-paper harness changes, including the baseline tool-surface fix (#334). Grades match the CSV row for row, per-arm pass rates equal the authors' `paired_marginals.csv`, and the paper's four headline cost ratios reproduce exactly. The artifact suite is the separate `onlycodes_artifact` benchmark because it is graded differently. No agent was re-run.
- **Curation decisions.** The model is the registry-mapped subject label; harness, version and arm are subject features, with the arm as `tool_mode` and the released label `onlycode` as `code_only`. Seeds are trials. Content is the task YAML's `problem_statement`; harness prompt wrappers are not stored. Reference answers are SWE-bench gold patches (62 Verified, 38 full), taken only where repository, base commit and held-out test patch match exactly. The verifier records `test_cmd`, the test patch and per-task pytest arguments; PASS requires the test patch to apply after the agent exits, at least one collected test, exit 0 and at least one executed, non-skipped test. The paper tag's two pre-agent source seed patches are attachments; two scikit-learn seed patches added later are excluded.
- **Limitations.** Agent identity combines model and harness, so cross-agent gaps do not isolate the model. Grading runs only each task's `test_cmd`, not full SWE-bench FAIL_TO_PASS/PASS_TO_PASS lists. Baseline runs predate #334; Codex restrictions add a prompt directive. Whether each seed patch applied, and the exact code revision of each run, are not recorded. Per-run logs are not released, so there are no traces.

Sources and grading are documented in [metadata.yaml](metadata.yaml); reviewed counts and checks are in [characterization.yaml](characterization.yaml) and [shared dataset checks](../../tests/test_benchmark_datasets.py).
